# TypeShuttle 使用指南

TypeShuttle 會把本機的文字「打字」送進瀏覽器版遠端桌面，或在遠端還原出一模一樣的小檔案。它只能單向傳送：從本機到遠端。

## 1. 安裝

1. 從 [Releases](https://github.com/shengwei-peng/typeshuttle/releases) 下載 `typeshuttle-<版本>.zip`。
2. 解壓縮到一個之後會保留的資料夾，例如「文件 › TypeShuttle」。
   - 資料夾被移動或刪除，擴充功能就會失效。
   - 打開資料夾要能直接看到 `manifest.json`，不要多包一層資料夾。
3. 在網址列輸入 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge）。
4. 打開「**開發人員模式**」。Chrome 在右上角，Edge 在左側欄。
5. 按「**載入未封裝項目**」，選擇第 2 步的資料夾。
6. 點網址列右邊的拼圖圖示，把 **TypeShuttle** 釘選到工具列。

找不到「開發人員模式」，或擴充功能顯示已停用時，瀏覽器可能受單位管理，請看[疑難排解](#8-疑難排解)。

## 2. 啟用遠端桌面網站

每個遠端桌面網址只需要做一次。

1. 登入並用瀏覽器開啟遠端桌面。
2. 點工具列的 **TypeShuttle** 圖示，按「**在此網站啟用**」。
3. 瀏覽器詢問是否允許存取這個網站時，按「**允許**」。
4. 面板出現文字框就完成了。不需要重新整理頁面，遠端連線也不會中斷。

TypeShuttle 只會取得這一個網站的權限，其他網站不受影響。

## 3. 用快捷鍵貼上

1. 在本機**複製**文字。
2. 在遠端桌面上**點一下要輸入的位置**，讓游標停在遠端。
3. 按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>（macOS 是 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>）。
   - **單行短文字**會立刻送出。
   - **多行，或超過 500 字**時，頁面上方會出現確認框。看過預覽後，按 <kbd>Enter</kbd> 送出、<kbd>Esc</kbd> 取消，或按 <kbd>P</kbd> 改用[精確傳輸](#5-精確傳輸程式碼與檔案)。精確傳輸需要遠端游標在終端機裡。
4. 打字時右下角會顯示進度，完成後右上角會出現「**已送出**」。

> [!IMPORTANT]
> **打字時請不要碰鍵盤和滑鼠。** 按任何鍵或點一下畫面，就會立刻停止。這樣可以避免你打的字混進去，或文字被送到錯的地方。

### 打到一半停下來時

提示會告訴你停在第幾行，**還沒送出的內容會自動放進工具列面板**：

1. 在遠端把游標移回停下來的位置。
2. 點工具列的 TypeShuttle 圖示，面板裡已經是剩下的內容。
3. 按「**送出到遠端**」。

### 在終端機要特別小心

遠端游標在終端機時，**多行內容的每一行打完就會立刻執行**。複製的內容結尾如果有換行，TypeShuttle 預設不會按下那個 Enter，讓你確認指令後再自己按。

## 4. 工具列面板

點工具列的 TypeShuttle 圖示開啟面板。想先檢查或修改內容，或要送檔案時使用。

- **直接打字**：貼上或修改文字，確認行數、字數和預估時間後，按「**送出到遠端**」。
  - 「**這次送出 Tab 鍵（Makefile 等）**」：預設每個 Tab 會轉成 4 個空格。只有一定要真正 Tab 字元的內容才勾選。
  - 「**換行鍵**」：在 Teams、Slack 等聊天程式裡，Enter 會直接送出訊息。要把多行當成同一則訊息時，改選 Shift+Enter。
- **精確傳輸**：見下一節。

## 5. 精確傳輸：程式碼與檔案

直接打字時，遠端程式可能會「幫忙」修改內容，例如自動縮排、自動補括號。精確傳輸會把內容壓縮後轉成英數字送出，在遠端還原成**完全相同的檔案**，還能用 sha256 核對。

**適合：** 程式碼、YAML、JSON、腳本；一個字都不能錯的內容；超過 2,000 字的長文字；1 MB 以內的檔案。

**步驟：**

1. 在遠端開啟**終端機**（bash），讓游標停在提示字元後面。
2. 點 TypeShuttle 圖示，切換到「**精確傳輸**」。
3. 貼上文字，或按「**或選擇檔案**」。
4. 面板會顯示檔案存到遠端的位置、原始大小、要打幾行、預估時間，以及 **sha256**。
5. 按「**送出到遠端終端機**」。
6. 送完後，遠端終端機會印出 sha256。**和面板上的值完全一樣，就代表檔案完全正確。**

檔案會存在遠端的 `~/typeshuttle-inbox/`。檔名開頭是日期與時間，例如 `2026-09-14_153012_deploy.sh`。原始檔名只保留英數字與 `.`、`_`、`-`，其他字元（例如中文）會被省略，但副檔名會保留。

打進遠端的指令長這樣，供參考：

```bash
mkdir -p ~/typeshuttle-inbox && base64 -d <<'TYPESHUTTLE_EOF' | gunzip > ~/typeshuttle-inbox/2026-09-14_153012_deploy.sh
H4sIAAAAAAAAA...
TYPESHUTTLE_EOF
sha256sum ~/typeshuttle-inbox/2026-09-14_153012_deploy.sh
```

**打到一半停下來時：** 遠端終端機會停在等待資料的狀態。請在遠端按 <kbd>Ctrl</kbd>+<kbd>C</kbd> 結束，再重新送出一次。

## 6. 送進 VS Code 等編輯器

編輯器會對打字做出反應：自動縮排、自動補括號、按 Enter 時接受自動完成建議。直接打進去的程式碼容易變形。建議二選一：

- **推薦：** 用精確傳輸存成檔案，再用遠端的編輯器開啟，或在遠端內部複製過去。遠端桌面**內部**的複製貼上不受影響。
- **一定要直接打進 VS Code 時，** 先暫時改掉下列設定，送完再改回來：

  | 設定 | 暫時改成 |
  |---|---|
  | `editor.autoIndent` | `none` |
  | `editor.autoClosingBrackets` | `never` |
  | `editor.acceptSuggestionOnEnter` | `off` |

## 7. 設定

在面板右上角點「**設定**」。所有設定修改後會自動儲存。

| 設定 | 預設 | 說明 |
|---|---|---|
| 送出速度 | 標準 | 遠端漏字或順序錯亂時，改成「保守」。「快」適合連線穩定、內容不長時。 |
| Tab 轉成幾個空格 | 4 | |
| 預設換行鍵 | Enter | 常貼到遠端聊天程式的話，改成 Shift+Enter。 |
| 保留結尾換行 | 關閉 | 開啟後，最後一行送完也會按 Enter。 |
| 超過幾個字要先確認 | 500 | 多行內容一律會先確認。 |
| 超過幾個字建議改用精確傳輸 | 2,000 | |
| 直接打字上限（字） | 50,000 | |
| 精確傳輸上限（KB） | 1,024 | |
| 遠端存檔目錄 | `~/typeshuttle-inbox` | 只能用英數字與 `. _ - /`，可以用 `~/` 開頭。 |
| 已啟用的網站 | | 移除網站時會一併收回權限。 |

## 8. 疑難排解

**按 Ctrl+Shift+V 沒有反應**
- 點 TypeShuttle 圖示確認：如果面板顯示「在此網站啟用」，代表這個網址還沒啟用。網址不同（例如換了伺服器）就要重新啟用。
- 先在遠端畫面點一下，再按一次快捷鍵。
- 出現「剪貼簿是空的，或只有圖片等非文字內容。」代表沒有可以打的文字。複製圖片無法送出。

**遠端漏字或順序亂掉**
到設定把「送出速度」改成「保守」。

**中文、日文會被遠端輸入法轉掉嗎？**
不會。TypeShuttle 送的是文字本身，不是按鍵代碼，所以在接受文字輸入的用戶端上，遠端輸入法是什麼模式都一樣。詳見 [clients](clients.md)（英文）。

**每一行都被當成指令執行了**
代表遠端游標在終端機裡。要在終端機建立檔案，請用[精確傳輸](#5-精確傳輸程式碼與檔案)。

**找不到「開發人員模式」，或擴充功能被停用**
瀏覽器可能受單位管理。開啟 `chrome://management`（或 `edge://management`），如果顯示瀏覽器受管理，請詢問管理員是否允許安裝擴充功能。

**瀏覽器提示「停用開發人員模式擴充功能」**
用「載入未封裝項目」安裝的擴充功能可能會出現這個提示。選擇保留即可。

**面板顯示「找不到遠端桌面」**
遠端還沒連上，或連線已經中斷。等遠端畫面出現後，按「**重新檢查**」。

## 9. 更新與移除

**更新：**
1. 把新版解壓縮，**覆蓋**原本資料夾裡的檔案。
2. 開啟 `chrome://extensions`，在 TypeShuttle 卡片上按重新載入（↻）。
3. 重新整理遠端桌面頁面，或關掉面板再重新開啟。

**移除：** 在 `chrome://extensions` 的 TypeShuttle 卡片上按「移除」，再刪除資料夾。
